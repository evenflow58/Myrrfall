# Myrrfall

Myrrfall is a Dungeons & Dragons campaign setting and the home of *Echoes of the Fallen Dawn*. This repository is the maintained reference for its world, campaign, and player-facing material.

## Choose Your Path

- **Players:** Start with the spoiler-free [Player Guide](docs/player-guide/README.md).
- **Dungeon Masters:** Browse the canonical [Lore Reference](docs/lore/README.md) or [Running the Game](docs/running-the-game/README.md).
- **Contributors:** Read [Contributing](CONTRIBUTING.md) before editing canon.

## Documentation Areas

| Area | Purpose |
| --- | --- |
| [Lore](docs/lore/README.md) | Canonical world, heroes, villains, factions, locations, creatures, NPCs, and items |
| [Running the Game](docs/running-the-game/README.md) | Mechanics, sessions, encounters, quests, tables, and campaign notes |

## Canon Policy

Material under `docs/` is canonical unless its front matter says otherwise. Drafts and competing versions belong under `ideas/`. See [Contributing](CONTRIBUTING.md) for editing and conflict-handling rules.
