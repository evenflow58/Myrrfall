# The Latticewild

**Theme:** Mutation Without Malice

Creatures here aren’t evil — they’re altered.

Examples:

- A deer that splits into three phased versions.

- A wolf that swaps gravity orientation.

- A crystal-skinned owlbear that sheds prismatic shards when hit.

### Scenario:

- A beast behaves in a patterned way — almost guarding something.

- Killing them destabilizes the ecosystem.

- Studying them reveals patterned magic, not chaos.

### Lore:

- The Expanse is evolving.

- Something is *teaching* the magic how to behave.
